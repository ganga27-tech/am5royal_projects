AM5 ROYAL – Developer Panel Document
1. Purpose
The AM5 ROYAL Developer Panel is a centralized frontend interface for developers to monitor projects, modules, APIs, tasks, bugs, team activity, databases, deployments, analytics, security, notifications, and system health.
2. Overall UI Layout
The interface follows a modern dark developer-console layout. It uses a fixed left sidebar, a top navigation bar, and a responsive main dashboard area.
Left sidebar: primary navigation grouped into Main, Development, Team, Infrastructure, Security, and System.
Topbar: global search, notifications, theme/settings controls, and developer profile.
Main content: dashboard cards, progress panels, system status, analytics, recent activity, bugs, projects, and deployments.
Responsive behavior: collapse the sidebar on smaller screens and use a mobile navigation drawer.

The deployment section separates the three main environments:

15. Important Functional Requirements
All dashboard values should be dynamic rather than hard-coded.
Sidebar navigation should route to separate functional pages.
API status, server health, and deployment status should support live backend data.
Tables should support search, filtering, sorting, pagination, and detail views.
Developer permissions should control access to sensitive database, deployment, and security operations.
Production deployment and rollback actions should require confirmation.
The UI should be responsive for desktop, tablet, and mobile.
16. Final Screen Flow
Login → Developer Dashboard → Projects / Modules / APIs / Tasks / Bugs → Developers → Database → Deployments → Analytics → Security → Notifications → Settings
Note: The supplied image is treated as the visual reference. The final frontend should preserve the same information hierarchy and overall dark developer-dashboard style while making all controls functional.
